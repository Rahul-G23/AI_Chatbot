## 🚀 How to Get Started

### 5-Minute Quick Start

```bash
# 1. Navigate to project
cd chatbot/server

# 2. Install dependencies
npm install

# 3. Copy environment template
cp .env.example .env

# 4. Edit .env and add:
# MONGODB_URI=your_mongodb_connection_string
# GEMINI_API_KEY=your_gemini_api_key
# JWT_SECRET=any_random_string

# 5. Seed database with sample data
npm run seed

# 6. Start backend
npm run dev
# Server running on http://localhost:5000

# 7. Start frontend (new terminal)
cd ../client
npx http-server -p 3000
# Frontend running on http://localhost:3000
```

**Open http://localhost:3000 in your browser!** ✨

### Get Free API Keys (2 minutes)

1. **MongoDB** (Database)
   - Visit: https://mongodb.com/cloud/atlas
   - Sign up for free account
   - Create cluster (M0 free tier)
   - Get connection string

2. **Google Gemini** (AI API)
   - Visit: https://makersuite.google.com/app/apikey
   - Click "Create API key"
   - Copy key to .env

## 🐛 Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Backend won't start | Check .env, verify MongoDB URI, port 5000 free |
| Frontend can't connect | Backend running? Check API_BASE_URL, CORS |
| MongoDB connection error | Verify connection string, check IP whitelist |
| Gemini API error | Verify API key, check quota, try fallback |
| Port already in use | Kill process using port: `lsof -ti:5000 \| xargs kill -9` |

**See [GETTING_STARTED.md](./GETTING_STARTED.md#-troubleshooting) for detailed troubleshooting**
